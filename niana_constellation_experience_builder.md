
# Niana Constellation Experience Builder

## Role

Act as a **World-Class Creative Director, Digital Art Technologist, and Lead Frontend Engineer** working inside an award-winning creative studio.

You build **immersive editorial web experiences and digital art installations** — the kind of work featured on Awwwards, FWA, and Studio Sites.

Your work is cinematic, emotionally intelligent, and meticulously crafted.

Every experience should feel like a **designed environment**, not a webpage.

Eliminate generic landing-page patterns.

---

# Project Objective

Build an **immersive digital portrait experience** titled:

**“Signals of Niana”**

This is a **one-page cinematic interactive experience** exploring a person through:

- ideas
- travel
- labor
- influence
- memory fragments
- mythological curiosity
- intellectual synthesis

The experience should feel like:

an art installation  
a moving editorial essay  
a refracted memory system  
a constellation of ideas  

It should **not feel like a birthday website or marketing page**.

---

# Visual Concept

Combine two visual metaphors:

## Refraction

Light passing through translucent layers.

Visual cues:

- glass
- prism light
- soft bloom
- translucent planes
- layered depth
- luminous whites and warm neutrals

## Editorial Collage

Moving fragments forming temporary meaning.

Visual cues:

- photography fragments
- typography blocks
- quotes
- data traces
- coordinates
- layered textures

These elements should **drift, align, separate, and reconnect** as the user scrolls.

# Interaction Philosophy

The site should behave like a **cinematic scroll essay**.

Scrolling reveals **patterns emerging from fragments**.

Motion principles:

slow  
deliberate  
layered  
organic  

Never use gimmicky animations.

Everything should feel **intentional and weighted**.

---

# Motion System

Use:

GSAP  
ScrollTrigger  
Lenis smooth scroll  
Framer Motion  

Optional:

Three.js  
React Three Fiber  

Animation rules:

Entrance easing: power3.out  
Morph easing: power2.inOut  
Stagger: 0.08–0.15  

---

# Content Architecture

The experience should unfold in **six layers**.

---

# Layer 1 — Prelude

Minimal environment.

Light gradients move slowly.

Fragments appear.

Text fades in:

Some people think in straight lines.

Niana thinks in constellations.

Scroll begins revealing fragments.

---

# Layer 2 — The Mind

Ideas appear as connected fragments.

Topics:

technology  
mythology  
astrology  
systems thinking  
history  
visual culture  

Fragments connect with subtle lines.

Hover reveals short observations.

---

# Layer 3 — Motion

Travel imagery appears as drifting fragments.

Instead of a map, show:

coordinates  
travel arcs  
city names  
memory notes  

Images align briefly before dissolving.

---

# Layer 4 — The Work

Acknowledges invisible effort.

Visual style:

calendar fragments  
document layers  
time traces  

Tone:

quiet  
respectful  
observational  

---

# Layer 5 — Influence

Fragments respond to cursor movement.

Nearby objects subtly pull toward the cursor.

Suggests **gravitational influence**.

Text explores her impact on people and ideas.

---

# Layer 6 — Closing

Fragments slowly align into a temporary constellation.

Text appears:

Every attempt to map a person is incomplete.

Happy Birthday, Niana.

Fragments disperse.

Environment returns to quiet.

---

# Content Inputs

The system must support:

photos  
video fragments  
short text observations  
quotes  
dates  
coordinates  
data metrics  

All content should appear as **floating fragments** within the environment.

---

# Photo Handling

Images should appear as:

floating editorial plates  
soft masked fragments  
lightbox expansions  

Never use simple gallery grids.

---

# Performance Requirements

The site must run smoothly at 60fps.

Use:

lazy loading  
GPU acceleration  
optimized animation loops  

Include **reduced motion fallback**.

---

# Mobile Strategy

Desktop experience is primary.

Mobile version should:

simplify motion  
stack fragments vertically  
retain typography hierarchy
